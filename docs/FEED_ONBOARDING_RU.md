# SMART BUY AI — подключение товарных источников (RU)

Дата актуализации: 2026-11-17

## Правила публикации данных

SMART BUY AI показывает цену, остаток, рейтинг и отзывы как фактические данные только если они получены из подключённого и разрешённого источника. Наличие магазина в каталоге не означает, что его товары уже индексируются.

## Формат удалённого реестра

Файл `catalog/feeds.json` читается сервером по `FEED_REGISTRY_URL`. Изменение этого файла не требует выпуска APK или пересборки сервера (кэш реестра — до 5 минут).

Пример записи (неактивная заглушка, не реальный источник):

```json
{
  "schema_version": 1,
  "version": "1.0.1",
  "feeds": [
    {
      "id": "merchant_example",
      "name": "Пример магазина",
      "url": "https://merchant.example/catalog.yml",
      "format": "yml",
      "active": false,
      "notes": "Включать только после разрешения владельца данных"
    }
  ]
}
```

Поддерживаемые форматы импорта backend: YML/XML, RSS/Atom и CSV. URL должен быть общедоступным HTTPS-адресом. Сервер проверяет URL, размер ответа и формат; HTML-страницы магазинов не считаются товарными фидами.

## Приоритет интеграций

1. Яндекс Маркет — подать заявку на партнёрскую программу и получить доступ к товарным данным/фиду. Seller Partner API не использовать как общий каталог чужих продавцов.
2. Wildberries — запросить разрешённый партнёрский фид/доступ. WB API продавца предназначен для кабинета конкретного продавца.
3. Ozon — получить подтверждённый доступ к каталогу/партнёрской программе; Seller API не использовать для чужого каталога.
4. AliExpress — получить одобренные affiliate/API credentials.
5. Alibaba — зарегистрировать приложение и получить необходимые API-права; отображать MOQ и цену партии отдельно.
6. Розничные магазины (DNS, Ситилинк, М.Видео, Lamoda, Hoff и др.) — подключать только публичные фиды или письменное/партнёрское разрешение.

## Что хранить при импорте

- внешний ID товара и ID предложения продавца;
- название, бренд, SKU/GTIN, категория;
- цена, валюта, наличие, регион/условия доставки;
- URL карточки товара и URL изображения;
- источник и время получения;
- условия/срок действия данных.

История цены записывается только при наличии достоверной цены из источника. Отзывы и рейтинг импортируются отдельно, с указанием источника и времени обновления.
