# Подключение реальных товарных фидов SMART BUY AI

Документ для подключения разрешённых товарных каталогов к серверу SMART BUY AI. Каталог магазинов (названия и категории) сам по себе не содержит товары, цены или наличие.

## Приоритетные источники

### 1. Pampadu

Pampadu объединяет товарные фиды партнёрских магазинов и позволяет сформировать единый YML-фид с фильтрами по категориям, брендам, цене, наличию и скидкам.

Порядок подключения:
1. Зарегистрировать площадку SMART BUY AI в личном кабинете Pampadu.
2. Подключить подходящие магазинные офферы и пройти модерацию, если она требуется.
3. Создать YML-фид с нужными категориями и доступным регионом/валютой.
4. Скопировать постоянную HTTPS-ссылку на готовый фид.
5. Передать ссылку администратору проекта для внесения в закрытый серверный реестр.

Официальная страница: https://pampadu.ru/tools/tovarnye-fidy/

### 2. Admitad

Admitad предоставляет фиды рекламодателей в YML, Google Merchant и CSV. Ссылки и дата последнего обновления доступны в кабинете для подключённой программы и площадки.

Порядок подключения:
1. Добавить площадку SMART BUY AI в аккаунт веб-мастера.
2. Подключить нужные программы магазинов и пройти модерацию.
3. В разделе «Товары» выбрать доступный фид и формат экспорта.
4. Проверить дату обновления рекламодателем и дату обновления Admitad.
5. Скопировать постоянную ссылку на экспорт и передать её администратору проекта.

Справка:
- https://support.admitad.ru/article/ru/86.html
- https://support.admitad.ru/article/ru/206.html

## Формат серверного реестра

Файл `catalog/feeds.json` обновляется отдельно от APK. Для каждого подтверждённого источника добавляется запись:

```json
{
  "id": "merchant_source_id",
  "name": "Название магазина или сети",
  "url": "https://provider.example/path/to/feed.yml",
  "format": "yml",
  "active": true,
  "notes": "Дата проверки свежести и условия использования"
}
```

Не добавлять в GitHub приватные токены, логины, пароли или персональные ссылки, если провайдер считает их секретными. Секретные URL хранить только в защищённых настройках сервера.

## Контроль качества перед включением

Источник включается только после проверки:
- URL доступен по HTTPS и ведёт на XML/YML/CSV, а не на HTML-страницу входа.
- Условия партнёрской программы разрешают показ товарных данных и ссылок в прайс-агрегаторе.
- Есть название, стабильный ID товара, цена, валюта и ссылка на товар.
- Изображение и наличие импортируются, если они предоставлены источником.
- Дата последнего обновления фида известна и достаточно свежая.
- Цены и наличие повторно проверяются по расписанию, заданному договором/провайдером; при ошибке или устаревании источник отключается от выдачи.
- Удалённые товары и недействительные офферы не продолжают показываться как доступные.

## Правила отображения в SMART BUY AI

- Не смешивать демонстрационные товары с реальными офферами.
- Не показывать устаревшую цену как актуальную.
- Показывать магазин, цену, валюту, время последней проверки и ссылку на товар.
- Для одного товара объединять предложения только при достаточном совпадении идентификатора/характеристик; не сравнивать разные комплектации как один товар.
- Не собирать данные через обход авторизации, CAPTCHA или технических ограничений магазинов.
- Обновление реестра и каталога не должно требовать обновления Android-приложения.

## Текущий статус

На момент создания документа в `catalog/feeds.json` нет активных подтверждённых партнёрских фидов. Публичный фид Irkeda оставлен выключенным до подтверждения свежести. Поэтому проект пока не должен заявлять, что цены по широкому ассортименту магазинов уже импортируются.
