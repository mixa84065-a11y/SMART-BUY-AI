# Источники товарных данных SMART BUY AI

Статус на 2026-11-17: реестр `catalog/feeds.json` подключён к backend через `FEED_REGISTRY_URL`, но активных фидов пока 0. Не считать магазин подключённым, пока сервер не скачал разрешённый фид и не импортировал реальные предложения.

| Источник | Что даёт | Условие подключения | Статус |
|---|---|---|---|
| Admitad | XML/YML/CSV-фиды отдельных рекламодателей | Аккаунт веб-мастера, одобрение оффера, разрешение на товарный фид и использование на SMART BUY AI | Ожидает доступа |
| Pampadu | Каталоги магазинов, экспорт в YML, deeplink | Регистрация, доступ к конкретным офферам и проверка правил площадки/трафика | Ожидает доступа |
| Plati / Digiseller | API каталога цифровых товаров, цены, описания, отзывы и продавцы | Регистрация и собственный API-ключ; отдельный вертикальный каталог цифровых товаров | Не подключён |
| Yandex Market Affiliate API | Реферальные ссылки и метаданные по известной ссылке/артикулу | Уже настроенные серверные OAuth/Place ID; API не предоставляет общий поиск каталога | Ограниченная интеграция |

## Почему фиды не добавлены автоматически

Публично доступный URL сам по себе не означает разрешение на повторное использование товарного каталога. Перед включением источника необходимо подтвердить правила программы, право отображать названия, фотографии, цены и остатки, а также правила deeplink/маркировки рекламы. Не использовать URL, полученные из закрытых кабинетов других пользователей, и не обходить CAPTCHA, авторизацию или ограничения сайта.

## Подключение одобренного фида

1. Получить постоянную HTTPS-ссылку на XML/YML/CSV-фид в личном кабинете партнёрской программы.
2. Убедиться, что в условиях оффера разрешено показывать товары на внешнем агрегаторе/мобильном приложении.
3. Добавить запись в `catalog/feeds.json` с уникальным ID, названием, URL, форматом и `active: true`.
4. После обновления GitHub сервер перечитает реестр в течение 5 минут; APK и код backend обновлять не требуется.
5. Проверить `/v1/sources` и результат импорта. Если фид недоступен, не отображать его товары.
6. Проверить актуальность цены/остатка, атрибуцию магазина, deeplink и маркировку рекламы до публикации.

Пример записи (нерабочий пример, домен зарезервирован и не является источником):
```json
{
  "id": "approved_shop_feed",
  "name": "Одобренный магазин",
  "url": "https://merchant.example/catalog.yml",
  "format": "yml",
  "active": true,
  "notes": "Оффер одобрен для отображения в SMART BUY AI"
}
```

## Правила отображения в SMART BUY AI

- Цена, валюта, наличие и время последнего обновления берутся из источника; нельзя подменять отсутствующие поля вымышленными значениями.
- Если источник не передаёт отзывы/рейтинг, эти поля не заполняются фиктивно.
- У каждого предложения сохраняются источник, ссылка на товар и время получения.
- При просроченных данных предложение помечается устаревшим или скрывается.
- Партнёрская ссылка используется только при разрешении программы и с требуемой маркировкой/атрибуцией.
