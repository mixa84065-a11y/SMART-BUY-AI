# SMART BUY AI — API Реферальной программы Яндекс Маркета

Статус: серверный адаптер добавлен в сборку Render; требуется API-ключ и идентификатор одобренной площадки для реального smoke test.
Дата проверки официальной документации: 17.11.2026.

## Что важно знать о возможностях API

Используется именно API Реферальной программы (Affiliate API), а не Seller Partner API.

Affiliate API НЕ предоставляет общий поиск по каталогу. В документации Яндекса указано, что метод `GET /search` удалён из справки начиная с версии 3.25 от 22 июня 2026 года. Поэтому SMART BUY AI не будет имитировать поиск или показывать весь каталог Яндекс Маркета как подключённый.

Поддерживаемые методы, которые описаны в текущем справочнике:
- `GET /partner/link/create` — создать партнёрскую ссылку для известного URL Яндекс Маркета. Ответ может содержать название, фото, цену, остаток, скидку и вознаграждение для этого товара.
- `POST /partner/article/create` — создать реферальный артикул для известного товара.
- `GET /partner/link/info` — получить сведения по известной ссылке/артикулу.
- `GET /orders` и `GET /order` — отчётность по заказам.
- `GET /marking` и методы маркировки — только при наличии соответствующего права и необходимости.

## Что добавлено в SMART BUY AI

Патч `patches/apply_v0516.py` добавлен в Docker build после существующих серверных патчей. Он добавляет FastAPI-модуль `backend/app/yandex_affiliate.py` и два маршрута:

- `GET /v1/integrations/yandex/status` — сообщает только факт наличия настроек; никогда не возвращает токен.
- `POST /v1/integrations/yandex/link?url=https%3A%2F%2Fmarket.yandex.ru%2F...` — сервером вызывает официальный `/v3/affiliate/partner/link/create`, возвращает разрешённые поля ответа и реферальную ссылку.

Защита и ограничения:
- секрет передаётся только в заголовке `Authorization: OAuth ...` с сервера Render;
- разрешены только HTTPS URL домена `market.yandex.ru`;
- таймаут запроса 15 секунд;
- ответы 401, 403 и 429 преобразуются в понятные ошибки без раскрытия секрета;
- API выключен до проверки ключа и площадки;
- поиск всего каталога не реализуется, потому что Affiliate API его не поддерживает.

## Переменные Render

- `YANDEX_MARKET_AFFILIATE_TOKEN` — секретный ключ Affiliate API.
- `YANDEX_MARKET_PLACE_ID` — ID одобренной площадки из раздела «Блоги» в кабинете Реферальной программы.
- `YANDEX_MARKET_API_ENABLED` — оставить `false` до подтверждения ключа и площадки.

Яндекс указывает, что ключ передаётся в заголовке `Authorization` со значением `OAuth <token>`. Не использовать seller `Api-Key`: это другой продукт.

## Следующий шаг после получения ключа

1. Вставить ключ в Render, не отправляя его в чат и не помещая в APK/GitHub.
2. Указать `place_id` одобренной площадки SMART BUY AI.
3. Проверить `/v1/integrations/yandex/status`.
4. После подтверждения настроек временно включить интеграцию и создать одну тестовую ссылку на известную карточку товара.
5. Проверить ссылку, название, изображение, цену и остаток в ответе; затем решить, какие поля разрешено показывать в приложении.
6. Только после успешного теста пометить Яндекс как подключённый источник ссылок/товарных данных. Не называть его полным каталогом.

## Условия отображения

Перед показом данных сверить действующую редакцию договора и список одобренных площадок (сайт и Android-приложение). Соблюдать требования к атрибуции/логотипу/ссылке Яндекс Маркета, географии, бесплатному доступу, размещению данных рядом с рекламой и неизменности полученных данных. Данные Яндекса не размещать в Premium-only разделах или рядом со сторонней контекстной рекламой, если соглашение этого не разрешает.

До успешной проверки API источник должен иметь статус «Ожидает API-доступ», а не «Подключён».
