# SMART BUY AI

Android-приложение для поиска товаров и сравнения предложений российских и международных магазинов.

## Текущая версия

- Версия: **0.5.9** (versionCode **19**)
- Android application ID: `com.smartbuy.ai` — не меняется, чтобы сохранить возможность обычного обновления.
- Интерфейс: русский язык, тёмная тема.
- Сборка: GitHub Actions, Android Java 17 / compileSdk 35.
- Подпись: постоянный release-ключ из GitHub Secrets; приватный ключ не хранится в репозитории.

## Что обновлено

- Расширен поиск по магазинам: добавлены супермаркеты (Перекрёсток, Пятёрочка, Магнит, Лента, Ашан, METRO, ВкусВилл), аптеки (Аптека.ру, ЕАПТЕКА, Здравсити), детские магазины (Детский мир, Кораблик) и бренды одежды (Zolla, SELA, Finn Flare, BAON).
- Расширен демонстрационный каталог: телевизоры, планшеты, мониторы, бытовая техника, мебель, матрасы, инструменты, одежда, косметика, книги, зоотовары, продукты и канцелярия.
- Уточнены подписи: примеры и условные цены больше не выдаются за реальные предложения трёх магазинов.
- Backend registry расширен новыми источниками.
- Защита импорта: парсер отклоняет NaN и Infinity в поле цены.
- Backend tests: 9 проверок.

## Как устроен поиск без API-ключей

Приложение открывает поисковые страницы публичной веб-индексации по выбранному магазину. Это не прямое подключение к каталогу продавца: результаты могут быть неполными или устаревшими. Реальные цены, наличие, доставка, отзывы и история цен появятся только после подключения разрешённых публичных YML/XML/RSS/Atom-фидов или партнёрских источников. Никакие демо-значения не выдаются за реальные.

## Сборка APK

1. Откройте **Actions → Build SMART BUY AI Android APK**.
2. Нажмите **Run workflow** (или дождитесь автоматической сборки после обновления `main`).
3. После успешного завершения скачайте артефакт **SMART-BUY-AI-v0.5.7-release**.
4. Исходный код после применения обновлений доступен в артефакте **SMART-BUY-AI-source-v0.5.7**.

Для подписи в **Settings → Secrets and variables → Actions** должны быть настроены:
- `SMARTBUY_KEYSTORE_BASE64`
- `SMARTBUY_KEYSTORE_PASSWORD`
- `SMARTBUY_KEY_ALIAS`
- `SMARTBUY_KEY_PASSWORD`

**Не загружайте** JKS-файл, Base64-ключ или пароли в публичный репозиторий.

## Статус интеграций и монетизации

- Названия магазинов в поиске — источники для перехода к публичным поисковым страницам, не подтверждённые API-интеграции.
- Backend поддерживает импорт разрешённых структурированных фидов, но фиды магазинов пока не настроены.
- История цен и отзывы начнут накапливаться только после импорта реальных данных.
- Рекламный блок и Premium-экран пока демонстрационные; рекламная сеть и Google Play Billing не подключены.
- Совместимость подписи с ранее установленной APK-сборкой необходимо проверить на устройстве. После перехода на постоянный release-ключ последующие обновления будут использовать тот же ключ.


## SMART BUY AI v0.5.6

The Android build now applies the v0.5.6 structured YML importer patch. It resolves category IDs, imports delivery costs and seller labels, and keeps declared wholesale minimum-order offers separate from retail comparisons. Live product prices still require explicitly approved public feed URLs configured on the backend; store directory entries alone are not live price integrations.


## SMART BUY AI v0.5.7
- Импорт YML учитывает название категории, стоимость доставки, продавца и минимальную оптовую партию.
- Обновление фидов теперь изолировано по каждому источнику: сбой одного магазина не блокирует остальные.
- Успешный фид кэшируется на 30 минут; неудачная попытка повторяется через 5 минут; ручное обновление обходит задержку.
- Это улучшение механизма импорта, а не подключение магазинов: цены появятся только после настройки разрешённых публичных фидов.


## v0.5.8 — CSV-фиды
Добавлена поддержка товарных CSV-фидов распространённых форматов Google Merchant и Яндекс: разделители запятая, точка с запятой и табуляция; импортируются название, цена, валюта, ссылка, бренд, GTIN, категория, наличие, продавец и доставка (если поля есть).

Для импорта по-прежнему требуется явно настроенный разрешённый HTTPS-фид. Наличие магазина в каталоге само по себе не означает, что он передаёт SMART BUY AI цены или отзывы.


## SMART BUY AI v0.5.9 — удалённый реестр фидов
- Backend умеет загружать активные источники товаров из catalog/feeds.json по переменной FEED_REGISTRY_URL.
- Реестр можно менять отдельно от APK: добавлять и отключать источники, менять URL товарного фида.
- Реальные цены появятся только после добавления разрешённых URL и успешного импорта. Пустой реестр не создаёт фиктивных подключений.
- Для работы этой функции на сервере backend необходимо один раз задать FEED_REGISTRY_URL=https://raw.githubusercontent.com/mixa84065-a11y/SMART-BUY-AI/main/catalog/feeds.json.

## Развёртывание API на Render

В репозитории подготовлен Blueprint `render.yaml` и Dockerfile `Dockerfile.render`. Он собирает backend из исходного архива и применяет актуальные патчи. Для постоянной истории цен используется SQLite на отдельном persistent disk.

1. Откройте Render Blueprint: https://render.com/deploy?repo=https://github.com/mixa84065-a11y/SMART-BUY-AI
2. Подключите GitHub и выберите репозиторий SMART-BUY-AI.
3. Проверьте план сервиса и постоянный диск перед подтверждением создания.
4. После успешного Deploy откройте адрес сервиса и проверьте `/health`.
5. В SMART BUY AI откройте Профиль → Подключение сервера и сохраните адрес вида `https://имя-сервиса.onrender.com`.

Blueprint использует платный сервис Render с постоянным диском: бесплатный веб-сервис засыпает, а локальные файлы на нём теряются; бесплатная база Render Postgres истекает через 30 дней. Секрет `API_KEY` генерируется Render автоматически и защищает операции записи и принудительное обновление. Публичные GET-запросы приложения остаются доступными без ключа.

После развёртывания сервер автоматически читает `catalog/feeds.json`. Сейчас список фидов намеренно пуст: добавляйте только публичные HTTPS-фиды, использование которых разрешено владельцем источника.
