# SMART BUY AI

Android-приложение для поиска товаров и сравнения предложений российских и международных магазинов.

## Текущая версия
- Android application ID: `com.smartbuy.ai` (не меняется).
- Интерфейс: русский язык, тёмная тема.
- Сборка: GitHub Actions, Android Java 17.
- Постоянный release-ключ хранится только в GitHub Secrets.

## Каталог и реальные предложения
Каталог магазинов и категорий обновляется отдельно от APK через `catalog/catalog.json`. Реальные цены, наличие, доставка, отзывы и история цен появляются только после подключения разрешённых публичных товарных фидов или партнёрских источников. Само присутствие магазина в каталоге не означает прямую API-интеграцию. Поддерживаются структурированные YML/XML/RSS/Atom и CSV-фиды; обход авторизации, CAPTCHA или ограничений сайтов не используется.

## Обновления без переустановки
Список магазинов, категорий и товарных фидов хранится в GitHub:
- `catalog/catalog.json` — каталог магазинов и категорий;
- `catalog/feeds.json` — реестр товарных фидов.
Изменения этих файлов приложение получает удалённо, без выпуска новой APK.

## Бесплатное развёртывание backend (Render + Neon)

Для старта используем бесплатный Render Web Service и отдельную бесплатную PostgreSQL-базу Neon. Это сохраняет данные между перезапусками Render и позволяет позже перенести PostgreSQL на платный сервер без изменения Android-приложения.

1. Создайте бесплатный PostgreSQL-проект на https://neon.tech.
2. В Neon откройте **Connect**, выберите базу и скопируйте connection string (лучше pooled connection string с SSL).
3. Откройте Blueprint: https://render.com/deploy?repo=https://github.com/mixa84065-a11y/SMART-BUY-AI
4. Подключите GitHub и выберите репозиторий SMART-BUY-AI.
5. При запросе переменной `DATABASE_URL` вставьте строку подключения Neon. Не публикуйте её и не отправляйте в чат.
6. Подтвердите создание сервиса. Render соберёт Docker-образ из репозитория; health check использует `/health`.
7. После успешного Deploy скопируйте публичный адрес сервиса и укажите его в SMART BUY AI: **Профиль → Подключение сервера**.

Blueprint использует бесплатный план Render. Бесплатный сервис засыпает после 15 минут без входящих запросов, а первый запрос после сна может ждать около минуты. Его локальная файловая система временная, поэтому SQLite на Render не используется для постоянных данных. Neon Free даёт PostgreSQL с ограничениями по объёму, времени вычислений и сетевому трафику; при достижении лимитов база может временно приостановить вычисления, но данные остаются. Проверяйте текущие лимиты на странице Neon перед эксплуатацией.

Секрет `API_KEY` генерируется Render автоматически. Публичные GET-запросы приложения доступны без ключа; операции записи и принудительное обновление защищены ключом.

## Переезд на платный сервер
Backend использует SQLAlchemy и PostgreSQL. При росте проекта можно перенести базу на платный PostgreSQL, обновив только `DATABASE_URL` в настройках Render или нового хостинга. До переезда следует сделать экспорт/резервную копию базы и проверить её восстановление. APK и application ID при этом менять не требуется.

## Сборка APK
1. Откройте **Actions → Build SMART BUY AI Android APK**.
2. Нажмите **Run workflow** или дождитесь автоматической сборки после push в `main`.
3. Скачайте артефакт `SMART-BUY-AI-v0.5.9-release`.

Для подписи должны быть настроены GitHub Actions Secrets:
- `SMARTBUY_KEYSTORE_BASE64`
- `SMARTBUY_KEYSTORE_PASSWORD`
- `SMARTBUY_KEY_ALIAS`
- `SMARTBUY_KEY_PASSWORD`

Не загружайте keystore и пароли в публичный репозиторий.

## Монетизация и интеграции
Рекламный блок и Premium-экран пока демонстрационные; рекламная сеть и Google Play Billing не подключены. Список фидов сейчас пуст намеренно: подключать следует только источники, разрешённые владельцем.
